# Assets Visuales Del Frontend

Esta carpeta contiene los recursos visuales usados por la interfaz Streamlit.

Placeholders preparados:

- `bilbao_map.jpg`: fondo principal del hero.
- `traffic_network.jpg`: fondo alternativo para red de tráfico.
- `urban_sensors.jpg`: fondo alternativo para sensores urbanos.

El frontend usa `bilbao_map.jpg` si existe. Si se sustituye por una imagen final de Bilbao, mapas, cámaras, sensores o grafos, debe mantenerse el nombre para no cambiar el código.
